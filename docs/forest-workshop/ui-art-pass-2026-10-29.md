# 목업 기반 UI 통합과 에셋 복원 — 0.6.16

## 구현

최신 사용자 지시인 그림 에셋 중심 꾸밈, 아이콘 활용, 불필요한 탭 통합을 적용했다. 기준 브랜치는 이전 아이콘 작업 `a2abaa8`을 포함한다. 서버 게임 규칙·저장 스키마·권한·API 계약은 변경하지 않았다. 클라이언트 표시·탐색과 에셋 목록, 빌드 출력을 변경했다.

- 공방 작업: 현재 작업 / 제작 설정 / 순서·적용의 세부 탭을 제거. 방식 선택 → 시설 → 현재 작업 → 생산 설정 → 재료 → 우선순위 → 적용 순으로 통합. 미적용 초안과 되돌리기는 유지하며 긴 화면은 스크롤한다. 생산 품목 선택기는 기존 게임식 pagePicker를 재사용한다.
- 작업 분야: 기존 허브·밀·잼과 새 메뉴의 나침반·망치 그림 재사용. 분야 선택과 해금 상태는 유지한다.
- 시설과 창고: 시설과 재고 보호를 한 화면으로 묶어 시설 / 창고 두 탭으로 정리. 기존 protection 진입 상태는 시설 쪽으로 호환한다.
- 탐사: 여정 지도와 탐험 준비를 통합. 읽은 이야기 탭은 기록 탐색을 위해 유지한다. 과거 journey 상태도 준비 화면으로 연결한다.
- 홈: 기존 workReportCard를 재사용해 아이템 그림과 수량을 복원하고 이야기 배너에 새 삽화를 연결. 공간을 억지로 압축하지 않고 세로 스크롤을 허용한다.
- 이야기: 야외 재사용 배경을 전용 실내로 교체. 글자·페이지·캐릭터는 DOM으로 분리한다.
- 초대: 전용 봉투 장면을 본문 위에 표시. 추첨·교환 동작은 유지한다.
- 우편: 실제 본문에 전용 편지지 적용. 편지 분류/보관/복귀는 유지한다. 주민 생성 편지나 발신인 초상 데이터를 임의 추가하지 않는다.
- 공통: 기존 종이 에셋을 보조 버튼과 선택기 바탕에 재사용. 하단 메뉴 선택 바탕은 아이콘과 이름을 함께 감싼다. 내부 선·그림자와 글자 강약을 일부 조정한다.

## 신규 그림 5개

ChatGPT 내장 이미지 생성으로 개별 제작. PNG 원본은 `/workspace/generated_images`에 보존하고 WebP만 패키지에 포함했다. 텍스트·수치·주민을 합성하지 않았다. 생성 출처는 각 manifest entry에 기록한다. 기존 87개 그림은 유지하며 전체 92개다.

장면은 960~1200px 너비, 삽화는 384px 너비, 편지지는 768px 너비로 인코딩했다. 편지지는 CSS border-image에서 위아래 200·좌우 190 원본 픽셀 기준으로 슬라이스하고, CSS 테두리 영역은 위아래 55·좌우 42px다. 긴 본문을 위해 중앙은 확장한다. 투명 에셋 두 개의 실제 알파 범위 0~255를 확인했다.

생성 방향: 따뜻한 손그림 숲속 공방, 갈색 윤곽, 크림·청록 계열. 지도는 길과 빈 터 3곳, 실내는 중앙의 비어 있는 바닥, 초대는 봉투 중심, 이야기 삽화는 작은 크기의 단순한 형태, 편지지는 중앙 85%의 빈 영역을 요청했다. 원본 목업을 픽셀 복제한 에셋이 아니다.

## 검증과 실행 범위

- 패키지 빌드, 클라이언트/서버 strict 타입검사, 전체 forest-workshop 회귀 검사.
- 에셋 수·경로·WebP·해시·크기·클라이언트 맵·배포 목록 일치 검사.
- 브라우저: 작업, 시설/창고, 탐사, 이야기, 초대, 우편, 메뉴. 관련 테스트에서 실제 패키지 이미지 바이트를 제공해 로딩과 기존 행동을 확인했다.
- 작업의 320px·22px 폰트에서 가로 넘침과 적용 버튼 도달 확인. 이 조건이 모든 화면에서 검증됐다는 의미는 아니다.
- 브라우저 테스트 데이터는 모의 상태이며 실제 엔진·실제 주민·추첨 서버 호출을 포함하지 않는다. 캡처는 `/workspace/forest-ux-review`에 보관한다. 재실행: `FW_ART_SCREENSHOTS=<기존 디렉터리> PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/forest-workshop-work.browser.mjs`.
- 실제 Android, 서버 설치/업데이트, 모든 15화면·모든 상태의 시각 검수는 아직 미완료.

# 공방·페어 AI 서술 지침 — 0.6.11

설정 → AI 지침 관리에서 세계 공통 지침(1,000자), 관계 → 지침 관리에서 페어 지침(500자)을 편집한다. 기본은 비어 있음/꺼짐. 사용 여부·글자 수·수정일·버전·저장·초기화를 제공한다. 초기화는 편집 초안만 바꾸며 저장 전에는 서버에 반영되지 않는다. 서버 응답 중 새로운 입력은 유지한다.

세계 데이터에 지침과 버전을 저장하고 백업에 포함한다. schema 8 세계는 schema 9로 변환해 비어 있는 지침을 받는다. schema 9로 저장한 세계는 이전 패키지로 열 수 없다. 생성 서비스는 활성화된 세계 지침과 현재 페어 지침만 JSON 선호 데이터로 전달하고 공유 기억 필터는 그대로 사용한다. 시스템 규칙과 출력 검증은 유지한다. 생성 manifest에는 당시 지침 버전만 추가하며 지침 본문을 진단용으로 복제하지 않는다. 기존 이야기 문서는 재작성하지 않는다. 우편 생성 적용은 우편 기능 구현 때 연결한다.

검증: 지침 스키마 변환·명령 검증·저장과 JSON 왕복·사용자 선호와 시스템 규칙 분리, 모의 모델을 사용하는 실제 이야기 서비스에서 세계/페어 지침의 프롬프트 반영과 manifest 버전, 지침 변경 후 기존 이야기 불변이 통과했다. 브라우저에서는 빈 지침 거부·초안 재렌더 보존·범위별 저장·초기화를 검사하고 [320px 페어 지침 화면](mobile-review/pair-guidelines-320.png)을 확인했다. 엄격 타입·format/lint·회귀 11개·카탈로그 lane/locale/ZIP 해시/릴리스 노트 검사도 통과했다.

미검증: 실제 모델이 적대적 지침을 항상 거부하는지, 장문 지침의 실제 출력 품질, 정상 카탈로그 설치와 기존 사용자 세계 업데이트/백업복원, Android 설치형 웹앱은 확인하지 않았다. 모델 제어를 완전히 보장한다고 주장하지 않는다. 지침을 통해 다른 페어의 기억을 프롬프트에 추가하는 경로는 만들지 않았다.

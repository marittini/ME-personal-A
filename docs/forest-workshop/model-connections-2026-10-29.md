# 기능별 AI 연결 — 0.6.16

설정 → 관리 → AI 모델 연결 설정에서 이야기 생성과 주민 설정 제안에 각각 엔진 기본 연결 또는 등록된 연결을 고른다. 엔진의 인증된 `/connections` 목록에서 ID·이름·모델명만 화면에 사용한다. 선택은 현재 브라우저의 로컬 설정이며 세계 백업에 포함되지 않는다. 서버 생성 요청에는 연결 ID만 전달하고, 키를 복사하거나 저장하지 않는다. 지워진 연결은 선택 화면에 표시되며 생성 실패 시 기본 연결로 대체하지 않는다. 이미 작성된 이야기는 다시 생성하지 않는다. 같은 이야기를 서로 다른 연결로 동시에 생성하려 하면 두 번째 요청을 거부한다. 주민 편지는 아직 생성되지 않아 연결 설정을 제공하지 않는다.

검증: P2와 P4 회귀에서 선택한 연결 ID가 각각 실제 서비스의 모델 호스트에 전달됨을 확인했다. Chromium 설정 픽스처에서 두 연결을 따로 선택하고 저장했으며, 15개 회귀·서버/클라이언트 엄격 타입·format/lint·카탈로그/ZIP 검사가 통과했다. 엔진 2.5.1 진입점 체크아웃의 격리된 320px 화면에서 연결 선택 목록과 기본값을 확인했다. 화면 캡처는 접기 배치 보정 전의 펼친 설정 화면이다. 이후 접기와 선택은 Chromium 픽스처에서 검증했다.

제한: 실제 외부 모델 연결 2개를 이용한 생성, Android 설치형 환경, 정상 카탈로그 설치/업데이트는 미검증이다. 목록 API가 없는 구버전 엔진에서는 설정이 실패 안내를 표시한다. 비용 발생 테스트는 수행하지 않았다.

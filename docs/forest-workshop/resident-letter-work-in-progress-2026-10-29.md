# 주민 편지 — 작업 중

주민 한 명이 아는 활성 기억만 `knownBy`로 골라 확정된 활동 결과·주민 설정·세계 지침과 함께 프롬프트를 만드는 순수 함수를 추가했다. 응답은 제목 80자, 본문 1,000자 이내의 JSON으로 검사한다. 이는 형식과 인지 범위의 기초 검사이며 생성된 문장이 사실인지 보장하지 않는다.

아직 모델 호출, 기능별 편지 연결 설정, UI, 결과 저장, 중복 생성 처리, 장기 저장, 백업·복원과 마이그레이션은 연결되지 않았다. 플레이어에게는 고정 활동 보고만 보인다. 기존 편지 200건과 활동 기록 100건 상한은 변경하지 않았다. 이 작업은 완성 기능이 아니다.

검증: 비공개 타인 기억과 중지 기억이 제외되는지, 잘못된 JSON·추가 속성·길이 초과가 거부되는지 순수 회귀를 실행했다. 엄격 타입·format/lint를 통과했다. 실제 모델과 Android, 사용자 데이터는 검증하지 않았다.

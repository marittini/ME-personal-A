# 게임 화면 참조 기록 — 2026-10-28

## 직접 확인한 자료

- [놀러와 마이홈, 인벤 개발 인터뷰의 게임 화면](https://static.inven.co.kr/column/2016/08/08/news/i12413674510.jpg): 왼쪽 화면에서 자원과 상태가 위에 있고, 장면 속 캐릭터·시설 가까이에 작업의 남은 시간이 표시되며, 주요 기능은 화면 가장자리에 모인다. 오른쪽 업적 화면에는 목표별 진행도와 보상이 같은 행에 놓인다. 이는 공개된 한 장면의 관찰이며 현행 게임의 전체 사용 흐름을 입증하지 않는다. - [재배소년 한국판 Google Play 공식 소개](https://play.google.com/store/apps/details?id=com.owlogue.mandrakeboys.kor&hl=ko): 게시된 홍보 이미지의 한 장면에 캐릭터가 있는 공간과 활동 종료까지의 시간이 함께 보인다. 홍보 이미지이므로 실제 모든 메뉴의 동작이나 가독성을 검증한 것은 아니다.

## 적용과 차이

홈의 작업 요약에서 실제 진행 중인 작업 하나의 이름과 남은 시간을 표시하고 누르면 기존 작업 보고를 연다. 작업 화면은 하단 메뉴에서 접근한다. 읽지 않은 작업 보고가 있으면 보고를 우선 표시한다. 종료 시간은 기존 서버 상태와 클라이언트 카운트다운을 이용하고 보상이나 완료를 생성하지 않는다. 작업이 없으면 표시하지 않는다. 이는 위 자료에서 관찰한 ‘상태를 활동 가까이 표시’하는 방식을 참고한 자체 구현이다. 그림과 인터페이스를 복제하지 않았다.

## 한계

실제 두 게임을 직접 설치해 조작하거나 영상의 전체 흐름을 비교하지 않았다. 이 자료만으로 게임 수준의 완성도, 실제 사용성 또는 작은 화면에서의 방해 여부를 확정할 수 없다. 특히 실제 Android 화면, 큰 글자, 캐릭터·버튼 겹침과 여러 작업 중 어느 작업을 우선 보여 줄지 사용자 관찰이 필요하다. 이 구현은 현재 첫 번째 진행 작업 하나만 보여 준다. 기존 보고와 한 화면에 두 항목을 모두 보여 주는 것은 추가 검토가 필요하다.

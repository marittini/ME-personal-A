# 홈 화면 개선 작업 상태

- 기준 main `17f4713`, 원격 작업 브랜치 `work/forest-ui-only-20261027`. 사용자 요청: 모바일 전체 화면과 스크롤 없이 주요 조작이 보이도록 개선.
- 첫 화면/초대/프로필의 빈 상태·원본 펼치기·닫기, 내부 개발 코드 노출과 홈 배경 겹침을 개선했다. 홈은 화면 높이에 맞춘 장면 및 작업 보고·이야기·미접속 요약을 사용하고 기존 상세 창과 메뉴는 유지한다. 지원하는 브라우저에서 사용자 탭으로 전체 화면을 요청할 수 있다. OS/웹뷰의 전체 화면 지원을 보장하지 않는다.
- 기존 회귀 8개, 엄격 타입 검사, 홈·세계·초대·프로필의 DOM 조작 검사는 통과. 크로미움은 환경상 실행에 실패하여 실제 모바일 화면 크기·잘림·전체 화면 API와 ME-personal에 설치한 후의 동작은 미검증이다. DOM은 시각·배치 검증을 대체하지 않는다.
- 작업·탐사·주민·설정 등 다른 화면과 작은 높이/큰 글꼴에서도 한 화면 안에 기능을 배치하는 작업이 남아 있다. 접근성 보장을 위해 매우 낮은 화면에서는 스크롤 폴백을 둔 상태다. 전체 요구 완료라고 주장하지 않는다.
- UI 소스만 원격에 보존한 중간 체크포인트다. 이 체크포인트의 기존 배포 번들·카탈로그는 소스와 다르며 설치용이 아니다. 별도 경제 기능 WIP 브랜치는 포함하지 않는다. 설치 패키지의 버전·ZIP·카탈로그를 재빌드해 함께 보존하고 실제 엔진 설치 및 검증을 완료해야 한다.

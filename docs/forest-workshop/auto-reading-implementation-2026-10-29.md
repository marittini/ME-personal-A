# 이야기 자동 넘기기 기본 설정

0.6.9 구현. 설정 → 표시에서 기본 꺼짐/켜짐과 간격 2~10초(기본 4초)를 선택한다. 이 브라우저의 표시 설정으로 저장하며 세계 백업 데이터나 음성 낭독 기능이 아니다. 새 이야기가 로드된 뒤 기본값을 적용하고, 읽는 동안 자동 버튼으로 이번 읽기만 변경한다.

질문, 기록 열기, 이야기 밖 이동, 브라우저 비활성/포커스 이탈, 컴포넌트 해제와 마지막 장면에서 정지한다. 정지 후 자동 재개하지 않으며 사용자가 자동 버튼으로 재개한다. 질문에 임의 대답하거나 마지막 보관을 실행하지 않는다.

검증: 실제 createStoryActions를 브라우저에 번들해 기본값·간격·질문·기록·명시 정지·화면 이탈·마지막 장면을 결정적 타이머로 검사했다. 실제 언어 모델을 호출하거나 기기 타이머 정확도를 측정한 시험은 아니다. localStorage 저장·읽기·손상 JSON·차단 환경, 설정 스위치와 간격 변경의 브라우저 검사가 통과했다. 엄격 타입, format/lint, 기존 기능 및 지면 회귀 10개, 카탈로그 lane·locale·ZIP/해시·릴리스 노트 검사도 통과했다.

실제 Android·설치형 웹앱 및 정상 카탈로그 설치, 실제 생성 이야기의 장시간 자동 재생은 미검증이다. client-entry의 blur/visibility 이벤트 연결은 코드로 확인했으며 테스트는 공개 정지 메서드와 타이머의 정지 조건을 검사한다.

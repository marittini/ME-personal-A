# 숲결 공방 화면 명세 (최종 목업 5보드 · 15화면 기준)

목업이 최종 UI/UX다. 화면 구성(영역, 순서, 크기 비율, 버튼 위치)은 목업을 그대로 따른다. 이미지 에셋이 없는
동안은 같은 자리를 CSS·코드 아이콘으로 그리고, P5에서 검증된 에셋으로 바꾼다. 아직 기능이 없는 요소는 자리와
모양을 유지한 채 **잠금(준비 중)** 으로 두고, 누르면 열리는 단계를 알려 준다(2026-10-26 소유자 결정).
목업 속 수치·문구 예시는 하드코딩하지 않는다(README). 잠금 요소의 단계는 `app/features.ts` 한 곳에서 관리한다.

표기: ✅ 동작 · 🔒 잠금(열리는 단계) · 🎨 에셋 대기(P5)

## 공통 틀

| 요소 | 목업 | 상태 |
|---|---|---|
| 하위 화면 머리 | 왼쪽 둥근 사각 뒤로 버튼, 가운데 나무 간판 제목 | ✅ 🎨 |
| 자원 막대 | 골드 칩, 초대권 칩, 톱니(설정) — 홈·작업·시설·탐사 화면 | 골드 ✅ · 초대권 🔒P3 · 톱니 ✅ |
| 하단 바 | 홈 · 작업 · 탐사 · 주민 · 초대, 선택된 탭은 녹색 바탕 | 홈 ✅ · 작업 ✅(창고) · 탐사 🔒P4 · 주민 ✅ · 초대 🔒P3 |
| 카드 | 양피지 바탕, 점선 테두리, 모서리 잎 장식, 잎 아이콘이 붙은 섹션 제목 | ✅ 🎨 |
| 주요 버튼 | 청록 넓은 버튼 + 양쪽 잎 장식 | ✅ 🎨 |

## 01 경영

**01-1 홈**: 왼쪽 위 간판 "숲결 공방" · 골드 · 초대권 · 톱니 / 그 아래 날씨 칩(도시·날씨·계절) · 우편 아이콘(새 편지 수) /
화면 절반 높이의 공방 장면(배경 + 주민 최대 2명 + 감정기호) / "공방이 잘 돌아가고 있어요" 카드: 최근 입고 아이템 2칸(+수량),
작업 보고 버튼, "자동 입고 완료" / 미접속 누적 바(n시간 / 최대 72시간, ⓘ) / 이야기 카드("먼저 챙겨 둔 몫", 그림, 화살표) / 하단 바.
상태: 날씨 칩 🔒P5 · 우편 🔒P4 · 장면 배경 🎨 · 주민 ✅(영입한 주민 최대 2명, 각자의 그림과 배치. 시작 주민 전엔 첫 자리가 "주민 맞이하기", 빈 자리는 초대 🔒P3) · 작업 보고 카드 ✅(지금 상태 제목, 안 읽은 보고의 많이 들어온 두 아이템 +수량, 작업 보고 시트, 자동 입고 완료) · 미접속 바 ✅(지난 부재 중 인정된 시간 / 최대 72시간) · 이야기 카드 🔒P4.
목업에 없는 1회성 "공방 시작 꾸러미"는 홈 위에 뜨는 시트로 보여 주어 화면 구성을 바꾸지 않는다.

**01-2 공방 작업**: 머리 + 자원 막대 / 분야 탭 5개(채집·재배·조사·가공·제작, 아이콘) / 자동 운영 ↔ 지정 횟수 토글 /
시설 카드(그림, 이름 Lv, 설명, 배치 변경) / 제작법 카드(그림, 이름, 설명) / 목표 재고 −/+ 와 현재·목표 막대 / 재료 사용 설정(보유·보호·사용 가능) /
재작 우선순위 목록(끌기 손잡이, 번호, 아이템) / 현재 작업 진행 막대·남은 시간 / ⓘ 재료 부족 안내 / 운영 규칙 적용 · 추천 설정.
상태(P3a): 채집 · 가공 탭 ✅(첫 플레이 테스트의 두 시설) · 재배 · 조사 · 제작 🔒P3b · 자동 운영 ✅ · 지정 횟수 🔒P3b · 시설 카드 ✅(Lv, 처리 속도, 누르면 시설과 창고) · 배치 변경 🔒P3b(주민 배치) · 제작법 · 목표 재고 · 재료 사용 설정 · 제작 우선순위(켜기/끄기, 순서, 추가) · 현재 작업(남은 시간) · 대기 이유 ✅ · 운영 규칙 적용 ✅ · 추천 설정 ✅(미리보기 후 적용, 되돌리기). 목업의 끌기 손잡이는 위/아래 버튼으로 둔다(터치에서 확실히 동작).

**01-3 시설과 창고**: 머리 + 자원 막대 / 시설 · 창고 탭 / [시설] 시설 그림, 이름 Lv → Lv, 효과 비교 표, 설명, 골드 강화 버튼 /
재고 보호 카드: 편집하기, 표(아이템 · 보유 수량 · 보호 재고 · 예약 재고 · 사용 가능) / 자동 판매 토글(꺼짐).
상태(P3a): 시설 고르기 · 강화(서버 비용) ✅ · 재고 보호 표 ✅(예약은 탐험이 생기는 P4 전까지 "–") · 편집하기 ✅ · 자동 판매 🔒P3b · [창고] 탭 ✅ 전체 목록 + 팔기(보호분 제외).

## 02 탐험·이야기·편지 — 🔒P4

02-2 공방 이야기(간판 + 기록·자동, 장면, 화자 이름표, 대사 상자, 진행 n/m, 계속), 02-3 우편함(받은 편지 · 보관함, 목록, 편지 본문, 발신인이 아는 근황, 보관 · 닫기).

## 03 주민·관계·초대
**03-1 주민**: 간판 + 리본 / 이름으로 찾기 + 필터 / 전체 · 캐릭터 · 페르소나 탭 / 주민 카드 격자(그림, 이름, 종류 태그, 분야 태그, 영입 완료) /
선택 주민 상세(그림, 이름, 태그, 패시브 · 기본 효과 → 현재 · 돌파 n/5, 주민 그림 · 프로필 · 관계) / 주민 불러오기 / 하단 바.
상태: 검색 ✅(입력 잠시 뒤 적용, 한글 조합 중엔 다시 그리지 않음) · 필터 ✅(모두 → 영입한 주민 → 초대 대기) · 탭 · 카드 · 선택 ✅ · 분야 태그 🔒P3 · 패시브·돌파 🔒P3 ·
영입 완료 ✅ / 초대 대기 🔒P3 · 주민 그림 · 프로필(원래 설정 ↔ 공방 세계 설정, 수정, 변경 이력) · 관계 · 주민 불러오기 ✅.
**03-2 관계**: 간판 + 리본 / 공유 주민(얼굴, "공유 주민" 이름표, A–B · A–C, "두 관계는 같은 세계에서 이어져요") / 페어 행(A × B 얼굴, 현재 관계, 최근 사건,
기억 보기 · 지침 관리) / "페어 지정은 연인 선언이 아니에요." / 페어 추가 · 변경 · 보관 / 하단 바.
상태: 행 · 현재 관계(친밀도 단계 이름, content/relations.ts) ✅ · 최근 사건 ✅(이야기가 생기는 P4 전까지 "아직 없어요") · 기억 보기 · 지침 관리 🔒P4 ·
페어 추가 ✅(어느 두 주민이든 — 캐릭터·페르소나 구분 없음, 한 주민이 여러 페어) · 변경 · 보관 ✅(보관 · 되돌리기). 목업에 없는 뒤로 버튼은 주민으로 돌아가는 길로 둔다.
03-3 초대(초대권·종표, 주민 초대 · 종표 교환 탭, 희망 주민 설정, 1회·10회 초대, 확률 보기·초대 기록, 종표 교환) — 🔒P3b.

## 04 설정
**04-1 설정**: 뒤로 + 간판 / "내 공방": 닉네임 칸 + 수정, 현실 날씨 칸(날씨 아이콘·도시) + 변경 /
"표시": 글자 크기 슬라이더(px) + "이렇게 표시돼요." 미리보기, 날씨 효과 토글, 자동 읽기 토글 /
"관리": 주민 그림 관리 · AI 지침 관리 · 기억 관리 · 저장 · 백업 / 녹색 안내 상자 "미접속 누적 상한 72시간" / 하단 문구 "자동화 규칙은 작업 화면에서 바꿀 수 있어요." / 하단 바.
상태: 닉네임 ✅ · 현실 날씨 🔒P5 · 글자 크기 ✅ · 날씨 효과 🔒P5 · 자동 읽기 🔒P4 · 주민 그림 관리 ✅(주민 화면으로) · AI 지침 관리 🔒P4 · 기억 관리 🔒P4 · 저장·백업 ✅.
목업에 없는 "다른 세계"·"연결 점검"은 저장·백업 화면 맨 아래 보조 행으로 둔다(복원이 새 세계를 만들기 때문에 필요).

**04-2 주민 그림**: 뒤로 + 간판 / 대상 리본 / 투명 체크 무늬 미리보기 / 파일명 · 가로×세로 · 용량 / 파일 선택 · 교체 / 규칙 안내 3줄 /
그림 크기 · 좌우 위치 · 기호 높이 슬라이더 / 적용 / 기본 배치 · 이전 그림 / 하단 바. 상태: 전부 ✅. 슬라이더는 놓을 때 미리보기가 따라오고, 적용해야 저장된다.
04-3 AI 지침 관리(적용 범위 선택, 세계관·이야기·편지·요약 탭, 주민별·페어별 지침, 사용자 추가 지침 + 임시저장 표시 + 글자 수, 적용 미리보기·변경 비교·이전 버전, 적용, 기본값 복원, 안내) — 🔒P4.

## 05 기억·백업·주민 등록
05-1 기억 관리 — 🔒P4. **05-3 주민 등록**: 뒤로 + 간판 / ① 자료 선택 → ② 재구축 → ③ 시작 주민 / 선택한 자료 / 원래 설정 / 공방 세계 설정 + n / 200 / 수정 · 다시 제안 /
주민 그림 직접 등록(PNG · WebP → WebP 저장) / "원본 프로필은 바뀌지 않아요." / 재구축 확정 / 나중에 그림 등록.
상태: 전부 ✅. 보드가 단계 막대로만 보여 주는 ①(캐릭터·페르소나 목록)과 ③(시작 주민 한 명 고르기)은 같은 틀로 그린다. 폼이라 하단 바는 숨긴다(§15.6).
다시 제안은 누를 때만 엔진의 기본 언어 모델을 한 번 부르고, 확정 전에는 아무것도 저장하지 않는다.

**05-2 저장·백업**: 뒤로 + 간판 / 저장 완료(체크, 마지막 저장 시각) / 저장 공간 사용량: 주민 그림 · 배경 · 기록 막대와 용량, ⓘ "그림은 WebP로 보관해요." /
백업 내보내기(포함 범위) · 백업 불러오기(새 세계로 복원) / 복원 미리보기: 주민 n명 · 페어 n개 · 그림 n개 / 새 세계로 복원 / ⓘ "현재 세계는 덮어쓰지 않아요." / 그림 이력 정리 / 하단 바.
상태: 저장 완료 ✅ · 사용량 ✅(주민 그림은 참조 중인 WebP 실제 크기, 배경은 P5 전까지 0) · 내보내기(WebP 포함)·불러오기·미리보기·복원 ✅ · 그림 이력 정리 ✅(확인 시트를 거쳐 정리).

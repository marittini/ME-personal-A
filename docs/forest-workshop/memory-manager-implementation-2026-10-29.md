# 기억 관리·페어 기억 보기 — 0.6.10

설정 → 관리 → 기억 관리에서 세계 소유자가 원장을 열고, 관계 → 기억 보기에서는 해당 두 주민이 모두 아는 기억과 공개 기억만 열람한다. 기억의 유형·상태·인지 주민·출처 이야기 ID·정정 원문 ID를 표시한다. 관리자의 전체 열람과 주민의 인지 범위를 구별한다.

사용 중인 기억은 정정하거나 사용 중지할 수 있다. 정정은 새 factId와 supersedes를 만들고 원문을 corrected 상태로 남긴다. 유형·공개 범위·인지 주민·출처는 그대로 계승한다. 정정된 원문은 복원할 수 없고 사용 중지한 기억만 다시 사용할 수 있다. 기존 이야기 본문은 변경하지 않는다. 기존 원장 한도 1,000건을 유지하되 앞으로 한도 초과 시 이전 기억을 버리지 않고 쓰기를 거부한다. 이미 삭제된 기록은 복원하지 않는다. schema 변경은 없다.

검증: 원문 불변·정정 연결·A의 비공개 기억이 A/B 공유 생성에 포함되지 않음·사용 중지/복원·한도 거부·JSON 왕복의 신규 회귀가 통과했다. 기존 기능·지면 회귀 10개도 통과했다. 페어 비공개 제외·정정 초안 재렌더 보존·정정/상태 명령 연결, 설정·주민 브라우저 테스트가 통과했다. [320px 브라우저 픽스처](mobile-review/memory-pair-320.png)를 확인했다. 캡처는 실제 사용자 데이터가 아닌 테스트 데이터이며 모달 본문을 탐색한 상태다.

인지 주민과 상태 필터를 제공한다. 미완료: 유형/본문 검색 필터, 직접 이야기 열기, 정정 이력 전용 탐색, 실제 엔진의 정상 카탈로그 업데이트·사용자 데이터 백업/복원·Android 설치형 웹앱 검증은 남아 있다. UI는 세 건씩 목록을 나누고 상세 하나를 표시하는 초기 관리 화면이다. 생성 모델의 실제 응답 검증은 하지 않았다.

# 작업 정렬·여백·우편·날씨 효과 — 0.6.18

## 범위

사용자 요청: 공방 작업 상단 아이콘/글자 중앙 정렬, 요소별 여백과 크기 재검토, 우편 숫자 제거 및 새 편지 표시, 날씨 효과 및 필요한 그림 제작.

클라이언트 표시 설정과 장식만 변경한다. 서버 게임 규칙·시간·생산·보상·저장 스키마·API·권한은 변경하지 않았다. 버전 상수와 배포 파일은 빌더로 갱신한다.

## 정렬과 공간

| 대상 | 적용 기준 |
|---|---|
| 분야 선택 | 아이콘과 글자를 한 묶음으로 가로/세로 중앙 정렬. 아이콘 1.7em, 묶음 간격 0.25em, 안쪽 여백 0.5em/0.2em, 최소 높이 4.4em. 다섯 분야를 함께 검증. 분야 이름은 목업에 맞춰 조사로 표시 |
| 시설 카드 | 안쪽 여백/내부 간격 0.65em/0.6em. 긴 이름 줄바꿈 허용. 좁은 화면의 그림은 3.8em |
| 시설 행동 | 360px 이하에서 버튼을 세로로 쌓고 문구 줄바꿈 허용. 확대 글자에서 글자만 겹치는 문제를 방지 |
| 자원 칩 | 좁은 하위 화면에서는 별도 줄에 배치. 숫자/아이콘끼리 침범하지 않음 |
| 생산물 카드 | 안쪽 여백 0.75em, 그림/본문 간격 0.7em, 그림 3.5em. 이름 1.1배·설명 0.875배, 행간 1.3/1.5 |
| 섹션 제목 | 본문 1.1배, 아이콘 간격 0.4em. 정보 제목이 주요 행동과 같은 무게가 되지 않도록 구별 |
| 본문·터치 | 기존 사용자 글자 크기 12~22px와 44px 터치 목표 유지. 작은 화면을 맞추기 위해 전체 글자를 강제로 줄이지 않음 |

기본 16px 및 320px·22px를 캡처했다. 단순 가로 스크롤 유무 외에 자원 경계 겹침, 시설 버튼의 텍스트 넘침도 검사한다. 모든 15화면의 모든 요소를 재설계했다는 의미는 아니다.

## 우편

상단 숫자와 숫자용 노드는 제거했다. 받은 편지 중 읽지 않은 편지가 있을 때만 작은 금색 반짝임 아이콘을 표시한다. 모두 읽었거나 보관된 편지만 있으면 표시하지 않는다. 접근성 이름은 `우편함` 또는 `우편함 · 새 편지 있음`이며 새 메시지 수를 읽지 않는다. 편지의 실제 읽음/보관 저장 규칙은 유지한다.

## 날씨 연출

- 맑음·흐림·비·눈을 설정 → 표시에서 선택. 홈의 날씨 칩을 누르면 같은 설정으로 이동한다.
- 현실 날씨 조회와 분리된 수동 배경 연출이다. 도시 위치 요청·외부 API·날씨 추정은 추가하지 않았다. 설정 문구에도 현실 날씨와 생산에 영향이 없음을 명시한다. 실제 도시 날씨 설정은 계속 준비 중이다.
- 맑음은 작은 해, 흐림은 구름, 비는 빗방울 10개, 눈은 눈송이 8개. 홈 장면 안에서만 표현하며 보고 카드·메뉴·이야기에는 덮지 않는다.
- 레이어는 `aria-hidden` 및 `pointer-events:none`. 주민/편집 버튼보다 뒤에 표시. 지면 편집 중에는 숨긴다.
- 동작 줄이기에서는 구름·입자의 애니메이션을 멈추고 정적인 표시로 바꾼다. 효과 끄기는 레이어를 제거한다. 타이머나 프레임 루프를 추가하지 않았다.
- 표시 설정은 기존 글자/계절 설정처럼 브라우저 localStorage에 저장. 차단·손상된 저장소에서도 기본 설정과 현재 세션은 동작한다. 세계 백업 데이터에 날씨 연출 설정을 넣지 않는다.

## 그림

내장 이미지 생성으로 `ui/weather-{sun,cloud,rain,snow}.webp` 4종 추가. 작은 크기에서 읽히는 단순한 파스텔 형태·투명 배경·질감 없음·텍스트 없음을 지시했다. 128×128 WebP로 패키징하며 원본 PNG는 제작 공간에 보존한다. 원본명·출처·크기·해시는 asset-manifest.json에 기록한다. 총 96개 에셋.

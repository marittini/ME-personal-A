# 작업 중: 초과 생산·자동 판매 (2026-10-27)

이 브랜치는 개발 중간 복구 지점이며 설치 가능한 완성 패키지가 아니다. 기존 자동 판매 설정은 유지하고 `continuous` 선택 시 판매 한도까지 생산하는 소스와 테스트를 추가했다. 원본 서버·클라이언트 코드의 타입 검사와 기존 회귀 8개 및 신규 회귀 1개는 통과했다.

원본 도메인으로 잼 보관 5·하루 8개 판매, 다른 수동 행동 없음의 30일 생산 계산: 30분·2시간·8시간·24시간·72시간 정산 모두 3,360 G, 583회 완료. 활동 리스, 플레이어 의뢰, 다른 생산 정책과 실제 서버/화면은 포함하지 않는다. 기존 정책의 수동 판매 비교는 baseline 문서 참고.

남은 작업: 전체 사용자 경험·판매 종료/일자 경계·작업 우선순위·백업/복원·30일 경제를 확장 검증한다. 에이전트 번들·10MB ZIP·카탈로그는 전체 저장소의 기존 항목을 보존하는 환경에서 빌드하고 함께 보존해야 한다. 이 체크포인트의 카탈로그와 배포물은 변경된 소스를 반영하지 않는다. 현재 엔진 의존성의 onnxruntime 네이티브 다운로드가 프록시 시간 초과로 실패하여 설치형 통합 테스트 미완료. 엔진 빌드·실제 패키지 설치·모바일 화면을 확인해야 한다.

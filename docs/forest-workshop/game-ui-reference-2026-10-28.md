## 적용과 차이

홈의 작업 요약에서 실제 진행 중인 작업 하나의 이름과 남은 시간을 표시하고 누르면 기존 작업 보고를 연다. 작업 화면은 하단 메뉴에서 접근한다. 읽지 않은 작업 보고가 있으면 보고를 우선 표시한다. 종료 시간은 기존 서버 상태와 클라이언트 카운트다운을 이용하고 보상이나 완료를 생성하지 않는다. 작업이 없으면 표시하지 않는다. 이는 위 자료에서 관찰한 진행 상태의 가시성을 참고한 자체 구현이다. 다만 재배소년의 실제 화면처럼 각 작업 대상을 장면에서 직접 선택하는 구조는 아직 구현하지 않았다. 현 공방의 요약은 첫 번째 작업 하나만 표시하고 보고를 열기 때문에, 어느 시설에서 무엇을 하는지와 시설을 눌러 변경하는 흐름은 충분히 대응하지 못한다. 그림과 인터페이스를 복제하지 않았다.

## 한계

실제 두 게임을 직접 설치해 조작하거나 영상의 전체 흐름을 비교하지 않았다. 놀러와 마이홈의 제작 선택 화면과 재배소년의 스토리 대화 화면은 이번에 직접 확인하지 못했다. 이 자료만으로 게임 수준의 완성도, 실제 사용성 또는 작은 화면에서의 방해 여부를 확정할 수 없다. 특히 실제 Android 화면, 큰 글자, 캐릭터·버튼 겹침과 여러 작업 중 어느 작업을 우선 보여 줄지 사용자 관찰이 필요하다. 이 구현은 현재 첫 번째 진행 작업 하나만 보여 준다. 기존 보고와 한 화면에 두 항목을 모두 보여 주는 것은 추가 검토가 필요하다.

## 실제 플레이 캡처: 탐험과 의뢰게시판

### 재배소년 탐험

[이용자 안내글: 품종개량/탐험](https://tsuya00.tistory.com/3436)의 실제 게임 캡처 4장을 직접 열어 확인했다. 게시글 최초 작성일은 2022년이며, 본문에 10주년 기능 추가 내용이 있어 일부 이미지는 나중에 갱신됐을 수 있다. 그림의 번호·화살표·설명은 작성자의 주석이다.

- 탐험 지도는 장소별 이름과 핀을 사용하고, 핀의 색과 숫자로 출발 가능한 탐험 수를 표시한다. 상단에는 탐험대장과 시간 단축 등 현재 설정이 보인다. 지도 전체가 한 번에 제시된 이미지지만, 실제 기기에서의 화면 이동 여부는 이 캡처만으로 단정할 수 없다.
- 장소의 탐험 목록에는 제목, 등장인물, 소요 시간, 인원·비용, 보상과 출발 또는 조건 확인 버튼이 항목별로 모인다. 잠긴 항목도 조건 확인을 할 수 있다. 연관 탐험을 모아 보여 주는 상세 화면에서는 완료와 미완료가 함께 보인다.
- 탐험 전 친구를 고르는 화면과 예상 소요 시간·탐험 티켓 화면도 확인했다. 이는 해당 게임의 소셜·재화 설계이며 숲결 공방에 그대로 도입한다는 뜻은 아니다.
- 현재 숲결 공방의 이야기 탐험은 페어를 고르고 ‘탐험 준비/여정/읽은 이야기’를 오가며, 현재 편의 준비물과 출발 버튼을 별도 영역에 보여 준다. 편 타일은 목록 표시이며 눌러 편을 직접 고르는 컨트롤이 아니다. 세 편의 연결과 현재 가능한 행동을 더 잘 보여 줄 여지가 있다. 현재 기능·서버의 조건과 데이터는 유지해야 한다.

### 놀러와 마이홈 의뢰게시판

[이용자 공략의 의뢰게시판 캡처](https://hanfanc.tistory.com/323) (2016)를 직접 열어 확인했다. 개별 카드에는 요청자 얼굴, 물품 그림, 현재/요구 수량과 골드·경험치·호감도 보상이 보인다. 선택된 의뢰는 아래에 요청자 그림·말풍선·물품·수량·보상과 ‘포기하기/준비하기’를 함께 보여 준다. 화면은 이전 버전의 한 사례다.

[공식 고객센터 설명](https://sites.google.com/skywalkgames.com/welcomemyhomekr/faq/%EA%B2%8C%EC%9E%84-%EC%8B%9C%EC%9E%A5%EC%9D%98%EB%A2%B0)은 NPC와 친구 의뢰의 보상 차이, 전체 거절과 대기 시간을 설명한다. 공식 페이지 이미지 서버는 403으로 화면을 직접 확인하지 못했으므로 해당 이미지를 본 것으로 취급하지 않는다.

현재 숲결 공방의 납품 창은 의뢰 제목, 각 재료의 필요·사용 가능 수량, 초대권·골드와 납품 버튼을 표시한다. 재고 보호와 서버 납품 검증이 이미 연결돼 있지만 화면상 요청자·선택된 의뢰의 일관된 상세 연출은 없다. 향후 디자인은 한 번에 파악할 정보와 요청자의 성격을 살리되, 기존의 하루 단위 의뢰·보호 재고·보상 지급 규칙을 임의로 바꾸지 않는다. 친구 간 거래, 강제 접속, 원본 아트는 복제 대상이 아니다.

이 비교는 실제 게임을 직접 조작하거나 전체 탐험·의뢰 여정을 재현한 결과가 아니다. 스크린샷은 각각 2016년 및 2022년 작성 자료로 현행 버전과 차이가 있을 수 있다. 디자인 개선 효과는 별도 시안과 사용성 테스트로 검증해야 한다.

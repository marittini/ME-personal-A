# UI PR 통합 검증 — 0.6.19

## 기준

GitHub API에서 확인한 최신 main `fd01ec083fd2e5ead4b2fe29c32df92c3ae4ad54`(PR #21 병합)을 디자인 작업 브랜치에 통합했다. 일반 fetch의 추적 ref가 과거 main에 머물러 정확한 SHA를 가져와 대조했다. 저장소의 issues는 비활성, staging 원격 브랜치는 없어 실제 기본 브랜치 main을 PR 대상으로 한다.

## 충돌 해결

- 날씨 표시 설정과 main의 용도별 AI 연결 설정을 모두 보존.
- 관리 아이콘 행과 main의 AI 연결 설정 UI/저장 검사를 함께 유지.
- 기존 전체 회귀에 날씨 설정 검사를 추가하고, main의 주민 편지/보관/트랜잭션 스냅샷 검사를 보존.
- 홈의 반응/이동·전체 화면·장면 보존 로직은 main 그대로 유지. 보존 장면의 식별값에는 날씨 설정을 추가해 연출이 바뀌면 새 장면으로 갱신한다.
- 이미 main에 배포된 0.6.16 ZIP은 main의 파일을 유지. 미발행 중간 0.6.17/18 ZIP은 PR 최종 차이에서 제외하고 0.6.19만 새 배포로 구성. CHANGELOG의 중간 작업 기록은 최종 0.6.19 항목으로 통합했다.
- 서버 소스의 main 대비 차이는 package-info의 버전뿐이며, 저장 스키마·권한·API 계약은 바꾸지 않았다. 생성 client/server/manifest/catalog/ZIP은 통합 소스로 재빌드했다.

## 검사 중 보정

320px 이야기 질문 화면에서 상단 컨트롤이 두 줄로 늘어 읽기 공간을 침범하는 것을 확인했다. 좁은 화면의 기록/자동은 44px 아이콘 버튼으로 표시하되 접근성 이름과 툴팁, 선택 상태는 유지한다. 두 프레임의 레이아웃 갱신 후 실제 화면 높이를 검사하며, 본문을 줄이거나 검사 조건을 완화하지 않았다.

- 클라이언트/서버 strict 타입검사, 패키지 빌드.
- 전체 forest-workshop 회귀(기존 주민 편지·보관·스냅샷 및 날씨 설정 포함), 화면 스크롤 키 검사.

# 하단 메뉴 그림 — 2026-10-29

사용자가 제공한 숲결 공방 초기 목업의 색감과 분위기를 참고하여 홈·작업·탐사·주민·초대 메뉴의 그림을 각각 생성했다. 단색 선 SVG는 이미지 로딩 실패 시 대체 표시로 유지한다. 그림은 장식용이며 버튼의 기존 이름과 선택 상태는 그대로 사용한다.

- 홈: 주황색 지붕의 간결한 공방.
- 작업: 잎과 작업용 망치.
- 탐사: 빨간 바늘의 나침반.
- 주민: 토끼와 다람쥐 주민. 사용자가 등록한 개별 주민 이미지를 대체하지 않는다.
- 초대: 잎 봉인이 있는 편지 봉투.

다섯 그림은 ChatGPT 내장 이미지 생성으로 만들고 원본 PNG를 보존한 뒤 투명 배경 256×256 WebP로 패키징했다. 서버 패키지 에셋 목록 및 크기·SHA-256은 `assets/asset-manifest.json`, `assets/asset-paths.json`과 빌더가 관리한다. AI 생성물에 다른 작가의 라이선스를 임의로 부여하지 않는다.

Chromium 모바일 모의 320px에서 다섯 그림의 로딩·버튼 이름·선택 상태·44px 이상 터치 영역·이미지 오류 시 SVG 대체와 탐사 이동을 확인했다. 실제 Android 설치·회전·큰 글씨·모든 화면에서의 시각적 일관성은 아직 확인하지 않았다. 이 다섯 메뉴 외의 공통 아이콘과 지도·이야기 실내·초대장 장면·편지지 전용 에셋은 별도 작업이 필요하다.

# 숲결 공방 시각 에셋 적용 현황

이 문서는 패키지에 포함된 그림과 실제 화면의 사용 위치를 기록한다. 원본 최종 목업 보드 및 실제 Android에서의 전체 비교는 수행하지 않았으므로, 이 목록이 디자인 일치나 시각적 완성도를 입증하지는 않는다.

| 에셋 | 현재 적용 위치 | 실패 시 또는 미적용 |
| --- | --- | --- |
| 계절별 공방 배경과 장면 | 홈, 공통 배경, 이야기 장면 | 홈·이야기는 CSS/SVG로 그린 장면을 대체 표시한다. 배경은 평면 색상으로 남는다. |
| 시설 다섯 종류 | 작업·시설 | 각 시설 그림이 없으면 집 모양 아이콘을 표시한다. |
| 아이템 그림 | 제작·재고·납품·탐험 준비물·홈 요약·작업 보고·시작 꾸러미 | `itemTile`은 알려진 아이템 에셋을 사용하고, 이미지 실패 시 항목별 아이콘 또는 상자 아이콘으로 대체한다. 이름과 수량은 별도로 남는다. |
| 감정 여섯 종류 | 이야기의 발화 주민 | 그림을 불러오지 못하면 글자·기호를 표시한다. |
| 제목 간판·양피지 패널·기본 버튼 | 공통 화면에 로드 성공 시 적용 | 로드 전·실패 시 CSS로 그린 기본 화면을 사용한다. |
| 선물 상자 | 시작 꾸러미 제목 | 실패 시 상자 아이콘을 표시한다. |
| 나무 패널 | 파일과 경로가 있으나 현재 사용 위치 없음 | 원본 디자인에서의 용도를 확인하지 못해 임의로 화면에 적용하지 않았다. |

탭과 탐험 지도, 각종 기능 아이콘은 현재 CSS/SVG로 그린다. 주민 그림은 사용자가 직접 등록한 이미지를 쓰며, 없는 경우 대체 인물이 표시된다. 기기 기본 선택창은 공통 목록 페이지 선택에서 게임 스타일로 교체했으나, 주민 선택과 설정 등 일부 필드에는 아직 남아 있다. 이 요소들의 그림 적용 여부는 원본 디자인, 사용성, 접근성을 함께 보고 결정한다.

검증: 시작 꾸러미의 선물과 아이템 이미지를 320px Chromium에서 불러오고, 이미지 오류 시 대체 아이콘과 텍스트·받기 버튼이 남는지 확인했다. 실제 엔진 설치 및 Android 기기의 레이아웃·이미지 로딩은 확인하지 않았다.

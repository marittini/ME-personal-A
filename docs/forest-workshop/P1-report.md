## 2. 모듈 구조 (리팩토링·원인 추적용)

서버 `src/engine/packages/server/src/services/forest-workshop/` — 각 폴더는 위쪽 폴더만 가져온다.

| 폴더 | 책임 | 오류를 찾을 때 |
|---|---|---|
| `host/` | 엔진 Capability 런타임의 구조적 타입. 엔진에 닿는 유일한 경계 | 엔진 API가 바뀌었을 때 |
| `content/` | 아이템, 시작 꾸러미 수치 | 수치·이름 조정 |
| `domain/` | 순수 규칙: 세계 모델(zod 단일 원천), 마이그레이션, 명령, 오류 코드·한국어 메시지, ID | 규칙 버그. 엔진 없이 테스트됨 |
| `store/` | 문서 읽기·쓰기(CAS), 명령 기록 | 저장 형식·revision 문제 |
| `services/` | 명령 실행(중복 방지·재시도), 세계, 백업 | 동시성·멱등성 문제 |
| `images/` | 그림 바이트 검사, WebP 변환, 전역 갤러리 | 그림 업로드 문제 |
| `diagnostics/` | P0 연결 점검 | — |
| `http/` | 라우트, 오류→HTTP 변환 | 응답 형식 문제 |

클라이언트 `src/engine/packages/client/src/features/forest-workshop/`

| 폴더 | 책임 |
|---|---|
| `app/` | 엔진 API 클라이언트 래퍼, 라우트별 함수, 저장소(store), 컨트롤러(모든 상태 변경·요청·재시도 ID), DOM 도우미, 백업 미리보기 |
| `screens/` | 화면별 렌더 함수(홈·설정·저장·백업·세계 고르기), 공용 레이아웃·아이콘·복원 패널, 연결 점검 패널 |

오류는 모두 `FwError(code)`로 통일: 코드는 테스트·로그·클라이언트가 쓰고, 메시지는 한국어로 사용자에게 보인다. 예상 밖 오류는 스택과 함께 엔진 로그에 남기고 사용자에게는 `internal`만 보낸다.

## 5. 발견·결정 사항

- **같은 명령 동시 재전송 경쟁 수정**: 한 탭이 세계를 쓰고 명령 기록을 쓰기 전 사이에 같은 명령이 오면 "이미 받은 보상"으로 잘못 거절되던 문제를 테스트로 찾았다. 명령 기록을 먼저 쓰고, 규칙 거절 시 같은 명령의 기록을 다시 확인하도록 고쳤다.
- **엔진 화면 위 떠 있는 버튼**: 엔진의 떠 있는 미디어 버튼(빨간 원)이 패키지 화면 왼쪽 위를 가린다. 엔진 쪽 겹침 순서 문제로, 이번 단계에서 엔진은 바꾸지 않았다.
- **명령 기록 누적**: `fw-command` 문서는 계속 쌓인다. ponytail: 정리 정책(세계별 최근 N개 보존)은 저장공간 정리 화면과 함께 P2에서 정한다.
- **백업 자산**: 0.2.0 세계는 그림을 참조하지 않으므로 `assets`는 항상 빈 배열이고, 자산이 든 백업은 거절한다. P2에서 WebP 포함·갤러리 ID 재매핑을 넣는다.
